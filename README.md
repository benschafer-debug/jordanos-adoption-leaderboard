# Jordano's Digital Adoption Leaderboard

Auto-generated public leaderboard (all 42 reps ranked by combined adoption = customer self-serve + Order Agent).

- `index.html` — the page served by GitHub Pages (do not hand-edit; it is generated).
- `data.json` — the data snapshot, refreshed from Snowflake by a daily routine.
- `build_leaderboard.py` — regenerates `index.html` from `data.json`.

Refresh: update `data.json`, run `python3 build_leaderboard.py`, commit + push. Pages redeploys in ~1 min.
